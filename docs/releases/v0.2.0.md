SparkCode 首次提供 macOS、Windows 和 Linux 桌面安装包，以及可独立运行的 CLI。

- 项目侧栏可以按目录分组，同一项目的会话可以共用分屏终端。关闭较窄的终端窗格后，其他窗格会立即恢复可用宽度。
- 左下角的用量面板可以刷新 Antigravity 分模型额度。Codex 额度查询能等待较慢的响应，本地统计也会识别重复的用量快照。
- Claude、Codex、OpenCode 和 Cursor 支持继续已停止的会话。替换请求带有图片、并在送达前被中断时，恢复会重新发送替换后的文字和附件。
- 从检查点恢复文件时，使用同一目录或其子目录的新任务会等到恢复结束。

### 下载与升级

macOS 下载对应芯片的 DMG，Windows 下载对应架构的 EXE。Linux 提供 AppImage 和 DEB。CLI 提供 macOS arm64、Linux x64/arm64 和 Windows x64/arm64 压缩包，校验和见 `SHA256SUMS`。独立 CLI 的 Antigravity 额度使用实例自身的凭据或原生额度命令；仅通过系统钥匙串登录的旧版企业实例可能无法显示额度。压缩包沿用上游的 `t3-*` 文件名，安装脚本提供 `sparkcode` 命令。

本地打包的 0.1.9 没有更新源，第一次请手动安装。此版的桌面更新与 CLI 下载使用 SparkCode 自己的 GitHub Releases。macOS 构建未经 Apple 公证，Windows 安装包没有发布者签名。
