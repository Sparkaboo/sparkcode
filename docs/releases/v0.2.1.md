SparkCode v0.2.1 修复了 Antigravity / OpenCode 额度自动刷新以及 Worktree 切换与恢复中的问题。

- **Antigravity 与 OpenCode 额度自动刷新**：定时状态检查会自动获取 Antigravity 原生额度报告，OpenCode 在首次读取成功后也会持续按周期轮询，连接的客户端可自动获得最新额度。
- **ACP / Antigravity Worktree 切换不再卡死**：修复单线程 ACP 会话调用 `t3_worktree_handoff` 切入 worktree 后一直停留在运行中且 `continuationPrompt` 无法自动续跑的问题，被截断的工具调用会正确收尾。
- **Worktree 退出与恢复闭环**：新增 `t3_worktree_detach` MCP 工具以及 Web、Desktop、Mobile 端的「Return to local checkout」切回本地工作区入口；worktree 目录缺失时分支选择器自动回退至项目根目录，分支已在其他位置检出时快速返回明确路径提示。

### 下载与升级

macOS 下载对应芯片的 DMG，Windows 下载对应架构的 EXE，Linux 提供 AppImage 和 DEB。CLI 提供 macOS arm64、Linux x64/arm64 和 Windows x64/arm64 压缩包，校验和见 `SHA256SUMS`。已安装 `v0.2.0` 的桌面端可直接通过内置更新升级，本地打包的 `0.1.9` 请手动覆盖安装。macOS 构建未经 Apple 公证，Windows 安装包没有发布者签名。
