SparkCode v0.2.2 移除了隐藏的遥测与外部数据拉取，新增删除会话即时物理清理与过期墓碑自动回收，并补齐了 Web/Desktop 设置面板中文本地化。

- **隐私与零遥测彻底清理**：移除 PostHog 遥测上报与设备身份追踪（`telemetryId` / `AnalyticsService` / `Identify`），用站点直连 `favicon.ico` 替代 Google Favicon 代理请求，移除启动期拉取上游 `ModelManifest` 的外部请求，并将 Provider 更新检查默认关闭。
- **删除会话真实物理清理**：删除会话（`thread.delete`）时立即物理删除 SQLite 中的消息正文、FTS5 全文检索索引、工具输出、计划、检查点、运行记录与历史事件，并在超过 1 天同步保留期且后台副作用结束后自动硬删墓碑与过期项目、回扫历史软删残留并通过 `incremental_vacuum` 回收磁盘空间。
- **设置面板中文本地化与双语文档**：对齐 Web/Desktop 设置面板中英文文案覆盖，补充完善中英文 README 说明。
- **仓库地址迁移**：同步 GitHub 仓库路径与自动更新、安装脚本地址至 `fyrko-labs/sparkcode`。

### 下载与升级

macOS 下载对应芯片的 DMG，Windows 下载对应架构的 EXE，Linux 提供 AppImage 和 DEB。CLI 提供 macOS arm64、Linux x64/arm64 和 Windows x64/arm64 压缩包，校验和见 `SHA256SUMS`。已安装 `v0.2.0` / `v0.2.1` 的桌面端可直接通过内置更新升级，本地打包的 `0.1.9` 请手动覆盖安装。macOS 构建未经 Apple 公证，Windows 安装包没有发布者签名。
